# 📚 Estudos de HTML e CSS

## 💻 Sobre o repositório

Este repositório reúne meus exercícios e atividades práticas desenvolvidos durante o curso Técnico em Informática para Internet do Senac.

O objetivo é registrar minha evolução no desenvolvimento web, desde os fundamentos de HTML até a criação de páginas mais estruturadas e estilizadas com CSS.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Git e GitHub

## 📖 Conhecimentos praticados

- Estrutura básica de documentos HTML.
- Utilização de tags semânticas (`header`, `main`, `footer`, `nav`).
- Criação de listas e menus com categorias e subcategorias.
- Desenvolvimento de formulários com HTML.
- Organização de elementos utilizando `div`, `class` e `id`.
- Aplicação de estilos básicos com CSS.
- Organização e documentação do código.

## 🛍️ Exercício: Estrutura de Loja Virtual

Atividade prática realizada em 06/10/2026, com o objetivo de desenvolver a estrutura inicial de uma página de comércio eletrônico.

**Elementos desenvolvidos:**
- Cabeçalho com espaço para logotipo.
- Campo de pesquisa.
- Menu de navegação com categorias e subcategorias.
- Espaços reservados para banners e produtos.
- Estrutura de rodapé.
- Aplicação inicial de cores utilizando CSS.

**Status:** Em desenvolvimento e aprendizagem.

Aprimorar meus conhecimentos em desenvolvimento web por meio da prática constante, aplicando os conceitos aprendidos em sala de aula e acompanhando minha evolução como desenvolvedora.
